# [OpenAPI Specification] 인허가 업소 정보

식품안전나라(식품의약품안전처)에서 제공하는 **인허가 업소 정보** OpenAPI 상세 스펙 문서입니다.

---

## 1. 기본 정보

* **서비스명**: 인허가 업소 정보
* **서비스 ID (serviceId)**: `I2500`
* **제공 기관**: 식품의약품안전처

---

## 2. 요청 주소 (URL)

| 구분 | URL 형식 / 예시 |
| :--- | :--- |
| **기본 요청 주소** | `http://openapi.foodsafetykorea.go.kr/api/keyId/serviceId/dataType/startIdx/endIdx` |
| **기본 샘플 URL** | `http://openapi.foodsafetykorea.go.kr/api/sample/I2500/xml/1/5` |
| **추가 요청인자 없을 시** | `http://openapi.foodsafetykorea.go.kr/api/인증키/서비스명/요청파일타입/요청시작위치/요청종료위치` |
| **추가 요청인자 있을 시** | `http://openapi.foodsafetykorea.go.kr/api/인증키/서비스명/요청파일타입/요청시작위치/요청종료위치/변수명=값&변수명=값2` |
| **추가 파라미터 예시** | `http://openapi.foodsafetykorea.go.kr/api/sample/I2500/xml/1/5/LCNS_NO=값&INDUTY_CD_NM=값&BSSH_NM=값&CHNG_DT=값` |

---

## 3. 요청 인자 (Request Parameters)

| 번호 | 변수명 | 타입 (필수 여부) | 변수 설명 | 값 설명 |
| :---: | :--- | :--- | :--- | :--- |
| 1 | **keyId** | STRING (필수) | 인증키 | OpenAPI 에서 발급된 인증키 |
| 2 | **serviceId** | STRING (필수) | 서비스명 | 요청대상인 해당 서비스명 (`I2500`) |
| 3 | **dataType** | STRING (필수) | 요청파일 타입 | `xml` : XML 파일, `json` : JSON 파일 |
| 4 | **startIdx** | STRING (필수) | 요청시작위치 | 정수값 입력 (예: `1`) |
| 5 | **endIdx** | STRING (필수) | 요청종료위치 | 정수값 입력 (예: `5`) |
| 6 | **LCNS_NO** | STRING (선택) | 영업고유구분번호 | 인허가번호 (추가 파라미터) |
| 7 | **INDUTY_CD_NM**| STRING (선택) | 업종 | 업종명 (추가 파라미터) |
| 8 | **BSSH_NM** | STRING (선택) | 업소명 | 회사/매장명 (추가 파라미터) |
| 9 | **CHNG_DT** | STRING (선택) | 최종수정일자 | `YYYYMMDD` 형식 (예: `20170101`) <br>※ 해당 변경일자 이후의 데이터만 필터링하여 출력 |

---

## 4. 출력 항목 (Response Fields)

| 번호 | 항목명 (Field) | 설명 (Description) |
| :---: | :--- | :--- |
| 1 | **LCNS_NO** | 영업고유구분번호 (인허가번호) |
| 2 | **INDUTY_CD_NM**| 업종 |
| 3 | **BSSH_NM** | 업소명 |
| 4 | **PRSDNT_NM** | 대표자명 |
| 5 | **TELNO** | 전화번호 |
| 6 | **PRMS_DT** | 허가일자 |
| 7 | **ADDR** | 주소 |
