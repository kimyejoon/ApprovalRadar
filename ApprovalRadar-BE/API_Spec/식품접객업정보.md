# [OpenAPI] 식품안전나라 - 식품접객업정보

식품의약품안전처(식품안전나라)에서 제공하는 **식품접객업정보** OpenAPI 상세 규격서입니다.

---

## 1. 기본 정보

* **서비스명**: 식품접객업정보
* **서비스 ID (serviceId)**: `I1200`
* **제공 기관**: 식품의약품안전처

---

## 2. 요청 주소 (URL Specification)

| 구분 | URL 구조 및 예시 |
| :--- | :--- |
| **기본 요청 주소** | `http://openapi.foodsafetykorea.go.kr/api/keyId/serviceId/dataType/startIdx/endIdx` |
| **샘플 테스트 URL** | `http://openapi.foodsafetykorea.go.kr/api/sample/I1200/xml/1/5` |
| **추가 인자 없는 경우** | `http://openapi.foodsafetykorea.go.kr/api/인증키/서비스명/요청파일타입/요청시작위치/요청종료위치` |
| **추가 인자 있는 경우** | `http://openapi.foodsafetykorea.go.kr/api/인증키/서비스명/요청파일타입/요청시작위치/요청종료위치/변수명=값&변수명2=값2` |
| **실제 호출 예시** | `http://openapi.foodsafetykorea.go.kr/api/sample/I1200/xml/1/5/CHNG_DT=값&LCNS_NO=값&CRET_DTM=값&BSSH_NM=값` |

---

## 3. 요청 인자 (Request Parameters)

| 번호 | 변수명 (Parameter) | 타입 (Type) | 필수 여부 | 변수 설명 | 값 설명 및 형식 |
| :---: | :--- | :---: | :---: | :--- | :--- |
| 1 | **keyId** | STRING | **필수** | 인증키 | OpenAPI 발급 인증키 (테스트 시 `sample` 입력) |
| 2 | **serviceId** | STRING | **필수** | 서비스명 | 요청 대상 서비스명 (`I1200`) |
| 3 | **dataType** | STRING | **필수** | 요청파일 타입 | `xml` (XML 파일) 또는 `json` (JSON 파일) |
| 4 | **startIdx** | STRING | **필수** | 요청시작위치 | 정수 형태의 데이터 시작 번호 (예: `1`) |
| 5 | **endIdx** | STRING | **필수** | 요청종료위치 | 정수 형태의 데이터 종료 번호 (예: `5`) |
| 6 | **CHNG_DT** | STRING | 선택 | 변경일자 (YYYYMMDD) | 변경일자 기준 이후 자료를 출력한다. <br>정수입력 : `20170101` (2017년 1월 1일) |
| 7 | **LCNS_NO** | STRING | 선택 | 인허가번호 | 영업고유구분번호 추가 필터링 값 |
| 8 | **CRET_DTM** | STRING | 선택 | 데이터생성일 | 데이터 생성일 기준 필터링 값 |
| 9 | **BSSH_NM** | STRING | 선택 | 업소명 | 업소명 추가 필터링 값 |
