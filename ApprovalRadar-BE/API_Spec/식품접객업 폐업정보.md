# [OpenAPI] 식품안전나라 - 식품접객업 폐업정보

식품의약품안전처(식품안전나라)에서 제공하는 **식품접객업 폐업정보** OpenAPI 상세 규격서입니다.

---

## 1. 기본 정보

* **서비스명**: 식품접객업 폐업정보
* **서비스 ID (serviceId)**: `I2819`
* **제공 기관**: 식품의약품안전처

---

## 2. 요청 주소 (URL Specification)

| 구분 | URL 구조 및 예시 |
| :--- | :--- |
| **기본 요청 주소** | `http://openapi.foodsafetykorea.go.kr/api/keyId/serviceId/dataType/startIdx/endIdx` |
| **샘플 테스트 URL** | `http://openapi.foodsafetykorea.go.kr/api/sample/I2819/xml/1/5` |
| **추가 인자 없는 경우** | `http://openapi.foodsafetykorea.go.kr/api/인증키/서비스명/요청파일타입/요청시작위치/요청종료위치` |
| **추가 인자 있는 경우** | `http://openapi.foodsafetykorea.go.kr/api/인증키/서비스명/요청파일타입/요청시작위치/요청종료위치/변수명=값&변수명2=값2` |
| **실제 호출 예시** | `http://openapi.foodsafetykorea.go.kr/api/sample/I2819/xml/1/5/CHNG_DT=값&LCNS_NO=값&CLSBIZ_DT=값` |

---

## 3. 요청 인자 (Request Parameters)

| 번호 | 변수명 (Parameter) | 타입 (Type) | 필수 여부 | 변수 설명 | 값 설명 및 형식 |
| :---: | :--- | :---: | :---: | :--- | :--- |
| 1 | **keyId** | STRING | **필수** | 인증키 | OpenAPI 발급 인증키 (테스트 시 `sample` 입력) |
| 2 | **serviceId** | STRING | **필수** | 서비스명 | 요청 대상 서비스명 (`I2819`) |
| 3 | **dataType** | STRING | **필수** | 요청파일 타입 | `xml` (XML 파일) 또는 `json` (JSON 파일) |
| 4 | **startIdx** | STRING | **필수** | 요청시작위치 | 정수 형태의 데이터 시작 번호 (예: `1`) |
| 5 | **endIdx** | STRING | **필수** | 요청종료위치 | 정수 형태의 데이터 종료 번호 (예: `5`) |
| 6 | **CHNG_DT** | STRING | 선택 | 변경일자 | 변경일자 기준 이후 자료를 출력한다. <br>정수입력 : `20170101` (2017년 1월 1일) |
| 7 | **LCNS_NO** | STRING | 선택 | 인허가번호 | 영업고유구분번호 추가 필터링 값 |
| 8 | **CLSBIZ_DT** | STRING | 선택 | 폐업일자 | 폐업일자 기준 필터링 값 (`YYYYMMDD` 형식) |

---

## 4. 출력 항목 (Response Fields)

| 번호 | 항목명 (Field) | 설명 (Description) | 비고 및 데이터 형식 예시 |
| :---: | :--- | :--- | :--- |
| 1 | **LCNS_NO** | 인허가번호 | 영업고유구분번호 |
| 2 | **BSSH_NM** | 업소명 | 상호명 |
| 3 | **PRSDNT_NM** | 대표자명 | 대표자 이름 |
| 4 | **INDUTY_NM** | 업종 | 일반음식점, 휴게음식점, 제과점영업 등 |
| 5 | **PRMS_DT** | 허가일자 | `YYYYMMDD` 형식 |
| 6 | **CLSBIZ_DT** | 폐업일자 | `YYYYMMDD` 형식 |
| 7 | **CLSBIZ_DVS_CD_NM** | 폐업상태 | 폐업 구분 명칭 (예: 폐업 등) |
| 8 | **LOCP_ADDR** | 주소 | 업소 소재지 주소 |
| 9 | **INSTT_NM** | 기관명 | 관할 허가/신고 관청 (예: `○○구청`) |
